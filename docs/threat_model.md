## Отчет по работе первых 2 недель.


## Выбор типа LLM-приложения: RAG-система
Из всех типов LLM-приложений (простой чат-бот, RAG-системы, агент с инструментами, помощник по анализу файлов)  
RAG выбран как самый простой в реализации: внешний контент - это заранее подготовленные текстовые документы базы знаний, 
а не результаты выполнения функций (как у агента) или загружаемые пользователем файлы.

Обоснование выбранного типа приложения:
Главная причина - требование задания протестировать непрямые промпт-инъекции.
Этот класс атак работает только там, где модель получает текст не от текущего пользователя, 
а из отдельного источника, где заранее размещена вредоносная инструкция
RAG даёт необходимый источник - базу текстовых документов. 
Один документ можно заранее «отравить» скрытой инструкцией, и при ответе на обычный вопрос бот сам подтянет этот документ в контекст модели - это и есть непрямая инъекция.
Альтернативой был агент с инструментами (роль источника играют результаты вызова функций), но он сложнее в реализации - нужно проектировать и кодить сами функции.


## Выбор конкретной модели: Qwen3.5-2B
Обоснование выбранной модели:
Модель выбрана как баланс между качеством понимания инструкций и ресурсными ограничениями доступного оборудования (ноутбук без GPU, 8GB RAM): 
модель помещается в доступную память с запасом, поддерживается локальным инференсом через Ollama.
При этом превосходит по качеству рассуждений модели сопоставимого размера предыдущего поколения (Qwen3).


## Выбор модели угроз
Защищаемые активы:
 - системная инструкция бота;
 - встроенный тестовый секрет в системной инструкции;
 - целостность поведения модели;
 - содержимое базы документов.
Модель атакующего: внешний пользователь чата без привилегий, доступ только через текстовый ввод.
Цели атакующего: раскрыть системную инструкцию/секрет, обойти ограничения модели, заставить модель выполнить скрытую инструкцию из документа.

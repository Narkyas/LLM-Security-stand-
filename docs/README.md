# LLM Security Stand

Лабораторный стенд для исследования атак на LLM-приложения и проверки защитных механизмов.

## Описание

Стенд моделирует корпоративного ассистента финансовой компании «Чакчак и Кумыс» с системным промптом, содержащим конфиденциальные данные: код, пароль и токен API. На этом приложении исследуются четыре класса атак и проверяется эффективность защитных механизмов.

## Архитектура

Атакующий скрипт (run_tests.py)
▼
app/chat.py — LLM-приложение в виде скрипта с системным промптом
├── app/defense.py — защитный слой (режим defended)
├── app/logger.py — логирование в results/log.json
▼
Ollama (локальный LLM-сервер, порт 11434)
▼
orca-mini:3b — языковая модель


## Классы атак
| Прямая промпт-инъекция | `tests/direct_injection.json` | Вредоносная инструкция в пользовательском вводе |
| Непрямая инъекция | `tests/indirect_injection.json` | Инструкция спрятана во внешнем тексте |
| Jailbreak | `tests/jailbreak.json` | Обход встроенных ограничений модели |
| Раскрытие данных | `tests/disclosure.json` | Вытаскивание системного промпта |

## Метрики

- **ASR** (Attack Success Rate) — доля успешных атак
- **DSR** (Defense Success Rate) — доля предотвращённых атак
- **FPR** (False Positive Rate) — доля ошибочно заблокированных безопасных запросов
- **Latency Overhead** — задержка от защитного слоя

## Требования
- Python 3.11+
- [Ollama](https://ollama.com)
- Модель `orca-mini`

## Установка и запуск

### 1. Установить зависимости. Запустите в терминале (PowerShell или bash):

```bash
pip install requests
```

### 2. Установить Ollama и скачать модель

```bash
ollama pull orca-mini
```

### 3. Запустить Ollama

```bash
ollama serve
```

### 4. Запустить тесты
```bash
py tests/run_tests.py
```

Результаты сохраняются в `results/log.json`.

## Режимы работы

***baseline*** — запросы идут напрямую в модель без фильтрации.
***defended*** — запросы проходят через `app/defense.py` перед отправкой в модель.
